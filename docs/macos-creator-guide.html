Poseidon · Community tools · macOS

From game to workshop.

Play the demo, inspect its models in Blender, and build isolated mods with the engine’s native tools.

Play

  1. Open Poseidon Launcher.app.
  2. Choose the installed Demo or Remastered data folder. The launcher checks for the configuration, base archives, and fonts.
  3. Select the matching edition and click Play. Fullscreen uses the desktop’s borderless fullscreen mode.

Game data is separate from the app. The original 2001 game files are not a complete Remastered installation. The free Steam demo provides a small starting point.

Change resolution and graphics detail in the game’s options. Changes to the launcher’s display mode apply the next time you start the game. A legacy command containing --window forces windowed startup; use --display-mode borderless instead.

Using a trackpad

Click with one finger for the left mouse button and two fingers for the right button. Enable System Settings → Trackpad → Point & Click → Secondary click. That menu also offers a bottom-right corner click. For a held right button, press and hold rather than tapping. Apple’s trackpad instructions.

Inspect models in Blender

  1. Install Poseidon-Blender-macos-arm64.zip through Blender’s Preferences → Add-ons → Install from Disk. Use the package matching Blender’s CPU architecture.
  2. Enable Poseidon P3D Model Importer.
  3. In the 3D viewport, open the sidebar with N and choose Poseidon. Set Game Data to the same folder used by the launcher.
  4. Click Scan P3D Models, select a model, and import it. For example, the demo contains data3d/str borovice.p3d, a pine tree.
  5. Use Material Preview to see the textures. The collections separate visual detail levels from collision and other special meshes.

The add-on is an importer. It preserves useful reference data, but it is not a complete Blender-to-P3D exporter. Saving a .blend does not update the game. Animated characters also need verified skeletons, selections, attachment points, and collision meshes.

The Mac workflow was tested with native Apple Silicon Blender 5.2.2: scanning the demo’s 14 archives found 455 models; the pine imported with seven LODs and its textures.

Build and inspect a mod

The optional PoseidonTools executable is inside the app at Contents/Resources/Engine/PoseidonTools. It can convert textures, inspect and binarize P3D files, and pack PBO archives. These examples assume you built from a source checkout:

tools="$PWD/dist/arm64-macos-rwdi-local/PoseidonTools"
"$tools" image convert source/grass.png source/nvl_grass/grass.paa --format DXT1
"$tools" model inspect source/nvl_grass/grass.p3d --all
mkdir -p mods/@grass/AddOns
"$tools" pbo pack source/nvl_grass mods/@grass/AddOns/nvl_grass.pbo
"$tools" pbo list mods/@grass/AddOns/nvl_grass.pbo

A game-ready addon needs a valid config.cpp and model/texture paths that match its PBO prefix. Use a separate mod folder for experiments. In the launcher, click Mods → Add and choose that folder. Remove it from the list to return to the base game. Later folders take precedence when the engine resolves matching files.

model convert input.p3d output.p3d writes the engine’s optimized ODOL format; it is not a general export from Blender. Keep editable source assets separately.

Try the grass study

The source includes examples/vegetation/build.sh, which generates an original static grass mesh with three detail levels, converts its opaque texture to DXT1, and packs a small addon. Add the generated @grass-study folder in the launcher, click Preview Model…, and open source/nvl_grass/grass.p3d. Press F1 in the viewer for its controls.

This is an editable pipeline prototype. It adds an object class without replacing vegetation in existing maps. General model export, character animation, and large landscape performance still need further work.

Build the Mac tools from source

bash cmake/build-macos.sh PoseidonGame PoseidonGameDemo PoseidonTools PoseidonFormatsDLL
bash cmake/package-macos.sh
python3 apps/tools/BlenderAddon/package.py \
  --library dist/arm64-macos-rwdi-local/PoseidonFormats.dylib \
  --output dist/Poseidon-Blender-macos-arm64.zip

The default deployment target is macOS 15.0. Local bundles are ad-hoc signed and are not notarized releases. The package contains the engine and license notices; it does not contain game data.

If something fails

Use Logs in the launcher. Each game session records a separate log in ~/Library/Application Support/Poseidon Launcher/Logs. A missing-data warning usually means the selected folder is one level above or below the actual installation, or the download is incomplete.

For Blender, use the matching native library beside the add-on’s Python files. The Mac library is named PoseidonFormats.dylib. The source tree includes a background smoke test that scans and imports real game assets without changing your Blender preferences.
